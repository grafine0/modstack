ModStack - Modular Web Development Stack Manager
================================================

Welcome to ModStack!

ModStack is a comprehensive development environment manager that makes it easy to install, configure, and manage web development tools like Apache, MySQL, PHP, and more.

Key Features:
• Easy installation of web servers and databases
• Automatic configuration and port management
• Project management with virtual hosts
• Extensible architecture for additional services
• Modern, intuitive user interface

System Requirements:
• Windows 10 or later
• .NET 8.0 Runtime (will be installed automatically if needed)
• Administrator privileges for service management

IMPORTANT - Administrator Privileges Required:
This installer MUST be run as administrator. Windows will automatically
prompt you for administrator access when you launch the installer.

If you don't see the UAC (User Account Control) prompt:
1. Right-click ModStackSetup.exe
2. Select "Run as administrator"
3. Click "Yes" when prompted

Installation:
This installer will set up ModStack in the directory you choose. The default location is C:\ModStack, but you can change this during installation.

What gets installed:
• ModStack application files
• Default service configurations
• Sample projects and templates
• Documentation and help files

After installation, you can:
1. Launch ModStack from the Start Menu or Desktop shortcut
2. Install web services (Apache, MySQL, PHP, etc.) from the Package Manager
3. Create and manage development projects
4. Configure virtual hosts and SSL certificates
